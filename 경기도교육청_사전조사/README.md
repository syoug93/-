# 경기형 학교시민교육 100인 토의 — 참여단 사전조사 구글폼

근거 문서: 「경기형 학교시민교육 100인 토의 실행계획서(안)」 v0.5.26 (2026. 10. 16.)
- Ⅲ-2 사전조사 [표 2]: 개인정보 동의, 배경 문항(성별·연령대·참여유형), 추가 사안
- Ⅴ-2 사전조사 개정 문항(안): Q1~Q12 (표 2와 다르면 이 최신안을 따름)

## 구글폼 만들기

1. https://script.google.com → **새 프로젝트**
2. `build_form.gs` 내용을 전부 붙여넣고 저장
3. 함수 `buildForm` 실행 → 권한 승인
4. **실행 로그**에서 다음 네 가지를 확인
   - 편집 URL (폼 수정용)
   - 응답 URL
   - 응답 시트 URL (응답이 자동으로 쌓이는 스프레드시트)
   - 개인별 링크 형식: `…viewform?…entry.XXXX={ID}`, `{ID}` 자리에 참여단별 확인번호를 넣어 솔라피로 발송

만든 폼과 시트는 실행한 계정의 내 드라이브 최상위에 생깁니다. 필요하면 프로젝트 폴더로 옮기세요.

## 폼 구성

| 쪽 | 제목 | 문항 |
| :-: | --- | --- |
| 1 | 안내·동의 | 응답자 확인번호(링크로 자동 입력), 개인정보 수집·이용 동의 (동의하지 않으면 바로 제출됨) |
| 2 | 응답자 정보 | 성별, 연령대, 직업·활동 유형 |
| 3 | 기본원칙 인식 | Q1 인지도, Q2 관심도 (원칙 설명 **전**) |
| 4 | 경기형 공통 원칙 필요성 | 국교위 원칙 요약·출처 → Q3 필요성, Q3-1 이유 |
| 5 | 학생의 현재 문제와 우려 | Q4 (최대 2개), Q5 (최대 2개) |
| 6 | 원칙별 중요도 | Q6 원칙 5개 중요도 표, Q7 우선 구체화 (최대 2개), Q7-1 이유, Q8 경기형 보완 기준 |
| 7 | 현장 정착 조건 | Q9 걸림돌 (최대 3개), Q10 필요 지원 (최대 3개), Q11 사례, Q12 주체·Q12-1 제안, Q13 추가 사안 |

## 실행계획서와 다르게 구현한 부분

- **5점 척도 + 잘 모르겠음 (Q2·Q3)**: 구글폼 선형 배율에는 ‘잘 모르겠음’을 넣을 수 없어 6개 선택지 객관식으로 만들었습니다. Q6은 ‘판단 어려움’ 열을 넣은 객관식 그리드입니다.
- **‘판단 어려움’ 단독 선택**: 구글폼에서는 ‘판단 어려움’과 다른 선택지를 함께 고르는 것을 막을 수 없습니다. 분석할 때 함께 고른 응답은 따로 처리합니다.
- **Q12 (주체 선택 후 제안 1개)**: 주체 선택(Q12)과 제안 입력(Q12-1) 두 문항으로 나눴습니다.
- **본인만 응답**: 구글 로그인을 요구하지 않고, 개인별 링크에 미리 채워진 확인번호로 응답자를 구분합니다. 확인번호가 중복된 응답은 분석할 때 정리합니다.
