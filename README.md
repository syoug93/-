# -
입찰 제안 준비와 결과 리뷰를 위한 RFP/제안서 모음

## 서식 (templates)

| 경로 | 내용 |
|---|---|
| `templates/fgi/FGI_결과보고서_템플릿.docx` | FGI 결과 보고서 작성 서식 (Word). 종합보고서 · 그룹별 보고서 · 작성 가이드 |
| `templates/fgi/FGI_결과보고서_템플릿.md` | 같은 서식의 Markdown 버전 (버전 관리·검색용) |
| `templates/fgi/tools/build_fgi_template.js` | Word 서식을 다시 생성하는 스크립트 (`npm i docx && node build_fgi_template.js`) |

FGI 서식은 2025 더불어민주당 서울시당 서울시장 후보 인식 FGI(4그룹·29명)의 종합보고서·그룹별 보고서 구조를 일반화한 것이다.
