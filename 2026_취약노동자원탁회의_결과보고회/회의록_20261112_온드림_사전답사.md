# 회의록 — 12/1 장관 주재 타운홀미팅 사전답사·운영 협의

- 일시: 2026.11.12.(목) 오전 (약 1시간 50분)
- 장소: 온드림 소사이어티 (서울 중구)
- 참석: 노동부, 노사발전재단, 온드림 측, 마마미디어, 코리아스픽스
- 출처: Plaud 녹음 「11-12 행사 기획: 타운홀 미팅 공간·프로그램·운영 설계」 AI 요약 (화자 이름·고유명사는 음성 인식 결과라 확인 필요)

## 1. 핵심 결정사항

| 구분 | 내용 |
|---|---|
| 규모 | 운영진·출연진·취재·중계 포함 약 70명 (좌석은 최대 80석) |
| 운영 시간 | 행사 약 2시간 + 원상복구·쓰레기 처리·점검 약 2시간 |
| 세팅 | **당일 오전 세팅** (9시 개관). 12월 20일경까지 대관이 이어져 전날 세팅·익일 철거 불가 |
| 공간 콘셉트 | 편안하고 수평적인 분위기. **3개 안을 제안받기로 함**: ① 따뜻한 연말안 ② 잔디·캠핑안 ③ 현장 기물·키비주얼 활용안 |
| 무대 | 장관(중앙) + 전문가 3 + 당사자 2, 사회자는 출연진 가까이 착석해 진행 |
| 프로그램 순서 | 참석자 소개 → 장관 모두말씀 → 발제 → 퀴즈 → 1부 → 명칭 시상 → 2부 → 포스트잇 의견 소개·마무리말 → 단체 촬영 |
| 국민의례 | 생략 |
| 자유발언 | 생중계를 고려해 발언자 약 9명 사전 지정 (1부 5명, 2부 4명), 좌석 분산·좌석배치도·이름표 준비 |

## 2. 대관 규정 (온드림)

- 무료 대관이지만 계약과 같음. **종료 후 원상복구, 쓰레기 전량 반출**, 복구 전후 사진 촬영 후 데스크에 완료 보고
- 배너·안내물은 행사 공간 안에만 설치. 단, 특정 출입구 앞에 X배너 가능
- 바닥 훼손 금지 (인조잔디는 먼지·청소 부담 큼)
- 마이크 사용 시 슬라이딩도어·폴딩도어로 공간 분리
- 화장실 1층·2층 사용 가능, 공용공간 청결 유지
- 질문 전 홈페이지 대관 가이드 먼저 확인 요청 (LED 규격, 테이블·의자 수, 케이블 등)

## 3. 제공 물품·설비

| 항목 | 제공 내용 | 비고 |
|---|---|---|
| 테이블 | 사각 12개, 원형 3개 (원형은 접히지 않음), 180 듀라 테이블 3개 | 추가분은 직접 반입 |
| 의자 | 기본 60개 + 추가 20개 = **최대 80석** | |
| 마이크 | 무선 2대 + 유선 최대 4채널 = **최대 6채널** (유선 1대 기본) | 추가 장비는 직접 준비 |
| 화면 | LED, 세로형 DID (지정 폴더에 영상 파일), POP 거치대 5개 | POP는 A3 출력물만 준비 |
| 노트북 | 연결 지원 가능 | 중앙+양쪽 화면은 노트북 2~3대 필요 (1대 확장은 화질 저하) |
| 음향·영상 | 현장은 전문 기술팀 아님. 외부 전문가 운용 가능 | 외부 장비를 현장 스피커에 연결하려면 별도 협의 |
| 인터넷 | 무선 양호, 생중계는 유선 권장 | 유선 케이블 제공 가능 |
| 주차 | 자체 주차장 없음, 물품 반입 시 잠시 정차 가능 | 장관·VIP 차량 동선 별도 확인 |

## 4. 카페·동선

- 카페는 행사 중에도 영업. 폴딩도어로 분리 가능. 행사 전·쉬는 시간에는 참석자 카페 이용 가능
- 케이터링은 행사 공간 안에서 운영. 커피는 카페 개별 주문 또는 일괄 정산 가능
- **장관·VIP 출입은 갤러리 라운지 쪽**이 적합 (카페 쪽 출입구는 닫음). 늦게 온 참석자는 폴딩도어 이용

## 5. 공간 연출 논의

- 캠핑안: 인조잔디 + 빈백 약 15개 + 캠핑 테이블·의자. 70명 수용에는 빈백만으로 부족
- 기존 테이블은 창고에 다 들어가지 않을 수 있어, 남는 테이블은 케이터링·스태프·기자석으로 활용
- 여러 종류의 의자·소품을 섞으면 지저분해 보일 수 있어 **시각적 통일성** 중요
- 연말안: 초록·빨강 색감, 선물상자, 허니콤보드·포맥스 제작물. "일하는 사람에게 평안한 휴식과 안식처"로 콘셉트 연결
- 키비주얼 연계: 등신대·캐릭터·문구에 반영. 캐릭터 등신대는 AI 원본 파일 필요
- 의상: 니트 등 부드러운 복장 제안 가능 (장관은 직후 일정이 있어 환복 여부 고려)
- 무대: 출연진용 작은 테이블(물), 장관 프롬프터 필요 가능성
- 기자석: 뒤쪽에 높이 있는 노트북 작업 테이블 (취재 인원은 직전까지 미확정)

## 6. 퀴즈·시상

- 모바일 퀴즈: 슬라이도·카훗·퀴즈앤 중 선택, QR 접속 객관식
- 연습문제 후 본 문제 약 6문항, **누적 점수제로 1·2·3위** 선정
- 사회자가 문제를 읽고 화면에 카운트다운 표시. 휴대전화 사용 안내 필요
- 상품 3개, 개당 약 2만원 수준 (사진에 잘 보이는 상자 형태 검토)
- 1위 인터뷰: 이름·하는 일·참석 소감
- 명칭 공모 시상: 수상자 1명, **장관 시상**, 상장 성격 폼보드. 시상은 무대보다 플로어 앞쪽에서
- 사진 요소: 꽃다발, 인형, 캐릭터 탈, 등신대 등 검토
- 포스트잇 의견판: 시작 전 "노동복지회의소에 기대하는 역할" 작성 → 말미에 장관·전문가가 몇 건 골라 소개·응답

## 7. 명칭·제작물

- 공식 명칭은 당일 공개 방향. 행사 제목(안): 타운홀 미팅 "일하는 사람 ○○를 함께 그리다" (녹음 인식이 불명확해 확인 필요)
- 키비주얼·X배너·폼보드·현수막·화면 문구는 **명칭·핵심 문구 확정 후 제작**
- 명칭이 25일에 나오면 주말 포함해 제작 일정 촉박
- 폼보드 약 60×40cm
- 화면: 행사 제목, 식순, 휴대전화 안내, 2층 화장실 안내. 참석자·전문가 소개 화면은 생략 방향

## 8. 생중계·기록

- KTV 중계 예상. 확인할 것: 카메라 수, 인원, 콘솔 테이블 규모, 음향 수신 방식, 담당자 연락처
- 유튜브 규격이면 현장 LED에 송출 화면 표시 가능 (미러링 문제 기술 검토 필요)
- 사진·영상 기록: 대변인실 운영 여부 재확인. 없으면 별도 촬영 인력 필요. 스케치 영상 필요 여부도 확인
- 카메라 위치는 시상·장관 동선·사진 구도 고려해 사전 협의

## 9. 참가자·정산·주차

- 명찰: **행사 하루 전까지 명단 받으면 제작**. 당일 변경 대비 빈 명찰·라벨지 준비. 겨울이라 가슴 부착형 (인쇄는 마마미디어, 코리아스픽스는 규격 안내·케이스 대여)
- 사례비 지급: 서명 + 계좌번호. 사전 양식으로 본인 확인, 당일 서명
- 주차권: 장관·VIP·발제자 등 약 10장 우선 검토 (환불 어려움 → 실제 차량 이용 여부 사전 확인). 일반 참석자는 제외
